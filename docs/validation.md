# 验证总览

本页只汇总 `CF_agent-wechat` 当前验证状态并提供记录入口。生产事实以带日期的验证
记录为准；旧 V1 文件是历史实验快照，不作为 CFserver 当前运行手册。

## 状态定义

- **已实现并实机验证**：在记录的 CFserver 生产基线上实际执行并观察到预期结果。
- **已实现但尚未实机验证**：实现入口存在，但目标现场场景未完成闭环。
- **规划中**：尚未形成可执行、可验收的当前生产能力。

## 回归要求

出现以下变化时，应建立新的带日期验证记录：

1. 镜像版本、Compose 或容器启动方式变化。
2. 显示环境、健康检查、持久化或 Token 权限变化。
3. 登录脚本、登录事件或设备信任状态变化。
4. Docker 网络或 Gateway 调用端点变化。
5. CFserver 重启、升级或回滚后需要重新确认证据。

回归必须脱敏，不得记录真实账号、联系人、聊天标识、服务器 IP、二维码、Token、
Token 指纹或密钥。
