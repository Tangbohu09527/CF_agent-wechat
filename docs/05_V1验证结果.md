# 05 V1 验证结果

> **历史实验（已废弃、非当前生产方案）**
>
> 本文封存早期固定实验环境的 V1 结果，其中 VNC/noVNC、XFCE 和旧 Compose 只
> 代表当时调试背景，不得作为 CFserver 生产 runbook。当前生产事实以
> [2026-08-13 生产验证](validation/2026-08-13-cfserver-production.md) 为准。

## 记录范围

当时实验覆盖 agent-wechat 的部署、登录、消息、部分文件、群聊、引用和合并转发
外层识别。`Verified` 只表示该轮固定实验环境实际通过，不能外推为当前生产复验。

历史实验环境使用 Debian 13、Docker、XFCE 和 noVNC/VNC。该桌面路径已经废弃，
当前生产固定 `ENABLE_VNC=0` 并使用容器内 `DISPLAY=:99`。

## 当时部署与运行结果

| 验证项 | 历史状态 | 当时结果 |
| --- | --- | --- |
| Docker 与实验室 Compose 启动 | Verified | 容器可运行 |
| 容器健康检查 | Verified | 健康状态正常 |
| 历史 noVNC/VNC 调试入口 | Verified | 当时可访问，现已废弃 |
| Docker 重启后微信登录 | Known Issue | 需要重新登录 |
| agent-server 登录状态 | Verified | 重新登录后恢复 |

当时实验室 Compose 和额外 VNC 修复资产与验证主机存在差异。这些差异已由当前
`docker/compose.cfserver.yaml` 的无 VNC 生产基线取代。

## 当时 API 结果

| 方法 | 路径 | 历史验证行为 |
| --- | --- | --- |
| GET | `/api/status/auth` | 返回登录状态 |
| GET | `/api/contacts` | 读取联系人 |
| GET | `/api/chats` | 读取聊天 |
| GET | `/api/messages/{chat_id}` | 读取指定聊天消息 |
| POST | `/api/messages/send` | 使用 `chatId` 与 `text` 发送文本 |
| GET | `/api/messages/{chat_id}/media/{local_id}` | 获取部分已识别文件的数据 |

响应 schema、分页、错误码、时间语义和跨版本兼容性没有由该轮实验冻结。公共记录中
的账号、聊天和消息标识必须使用占位符。

## 当时消息能力

- 文本发送与消息读取通过。
- 消息读取曾观察到发送者、内容、时间和自身消息标记等字段。
- 群消息、发送者和群文件识别通过。
- 文本与文件引用的上下文读取通过。
- `txt`、`zip` 文件消息可被识别并获取数据。

这些结论不表示图片发送、API 文件发送、所有文件格式或上层附件处理已经完成。

## 合并转发消息

该轮实验能够读取合并转发消息的外层消息、发送者和标题。使用 media API 获取内部
内容时返回不支持，因此准确边界是：

- 外层存在性、发送者和标题识别：历史实验已验证。
- 内部聊天记录、文本和文件展开：未支持。

## WebSocket 消息事件

`/api/ws/events` 当时可以建立连接，但没有观察到微信新消息事件。该能力保持
`Pending Investigation`，不能对外宣称实时消息事件已经可用。

## 当时的跨项目关系

早期 Staging 曾验证外围调用方通过 agent-wechat 读取并回复微信文本。本文只保留
这个调用关系结论；外围系统的身份、权限、线程、AI 调度、消息存储和防回环实现不属于
本项目文档范围。

## 历史限制

- VNC/noVNC 和额外修复服务只属于历史实验，已废弃、非当前生产方案。
- 微信客户端登录与容器健康是不同状态源。
- 部分文件入口识别不等于系统文件处理或压缩包内容解析。
- 图片发送、API 文件发送和实时消息事件未验证。
- 历史跨项目文本联调不表示媒体、文件、Skills 或生产可靠性已经完成。

当前接口边界见 [API 文档](api.md)，当前三态矩阵见 [验证总览](validation.md)。
