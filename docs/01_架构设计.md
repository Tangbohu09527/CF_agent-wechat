# 01 架构设计

## 当前规划架构

```text
员工微信
   ↓
agent-wechat
   ↓
CF_gateway
   ↓
Hermes Agent
   ↓
Skills
   ↓
自动化执行
```

执行结果沿调用链返回至员工微信。当前文档记录目标边界，不代表相关组件已经接通或部署。

## 组件职责

### agent-wechat

负责微信通信，包括消息接收与回复等微信侧能力。agent-wechat 作为外部依赖独立获取，本仓库不包含或修改其源码。

### CF_gateway

负责未来的企业逻辑与系统桥接，包括协议适配、身份映射、权限校验、审计和请求编排。对应项目目录为 `cf-gateway/`，目前仅创建目录，不实现代码。

### Hermes Agent

负责 AI Agent 的理解、决策和执行编排。当前阶段不进行连接。

### Skills

负责提供可复用的具体能力和自动化流程，由 Hermes Agent 在后续阶段按权限调用。

## 分层原则

- 微信通信能力与企业业务逻辑分离。
- 企业扩展优先在 CF_gateway 实现。
- Hermes 保持 Agent 执行职责，不承担微信协议细节。
- 所有跨层接口在实现前先完成验证和契约设计。
