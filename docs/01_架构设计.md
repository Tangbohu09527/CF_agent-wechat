# 01 架构设计

## 当前架构

```text
员工微信
    ↓
agent-wechat
    ↓
CF Gateway
    ↓
Hermes Agent
    ↓
Skills（后续阶段）
    ↓
企业系统
```

V1 Staging 已完成从微信文本消息到 Hermes 响应并返回微信的闭环。Skills、企业
知识库和企业系统自动执行仍属于后续阶段，不能从架构图推导为已经接通。

## 组件职责

| 组件 | 职责 | 当前状态 |
| --- | --- | --- |
| agent-wechat | 微信账号、消息收发、联系人/聊天管理、媒体入口、事件接口 | 文本收发及部分入口能力 **Verified** |
| CF Gateway | Polling、消息存储、身份解析、权限准入、Employee Workspace、AIThread、Hermes 调度和路由 | V1 Staging 文本链路 **Verified** |
| Hermes Agent | 文本理解、响应生成和线程绑定 | V1 Staging API 调用与响应 **Verified** |
| Skills | 经授权执行可复用企业能力 | **Pending** |
| 企业系统 | ERP、知识库和其他业务数据与动作 | **Pending** |

## agent-wechat 边界

agent-wechat 可以暴露微信侧数据和动作，但不基于消息内容做 AI 推理，不直接持有
ERP 等企业系统的高权限凭据，也不实现企业审批或业务规则。入口侧已经验证
`txt`、`zip` 文件消息识别和 Base64 获取，但系统级图片理解、附件传递、文件处理、
OCR 和压缩包解析均未完成。

## V1 Staging 文本数据流

```text
员工微信
    ↓
agent-wechat
    ↓
CF Gateway WeChat Polling
    ↓
Message Store
    ↓
Identity Resolution
    ↓
Permission Admission
    ↓
Employee Workspace
    ↓
AIThread
    ↓
Hermes Dispatch
    ↓
Hermes API
    ↓
Hermes Response Relay
    ↓
WeChat Outbound Sender
    ↓
微信回复
```

当前接收路径使用 Polling；`/api/ws/events` 只验证了连接建立，尚未观察到新消息
事件，不能写成当前实时接入方式。Gateway 调用 agent-wechat 文本发送接口时使用：

```json
{
  "chatId": "...",
  "text": "..."
}
```

旧字段 `content` 不符合 `POST /api/messages/send` 的已验证请求契约。
agent-wechat 原始响应字段为 `isSelf`。Gateway Polling 将它解析为
`RawWechatMessage.is_self`，并在 normalize/sink 之前过滤值为 `true` 的自身消息：

- 不进入 normalize 或 sink。
- 不进入 permission admission。
- 不调用 Hermes。
- 仍推进 checkpoint。

该行为避免机器人回复再次触发 Hermes，同时保持现有 at-least-once delivery 和
checkpoint 语义。

## 集成原则

- CF Gateway 是企业集成入口，负责隔离 agent-wechat API 变化。
- Gateway 不依赖微信 GUI 登录状态，而以 agent-wechat session/API 状态为准。
- 登录初始化必须通过 `/api/ws/login` 完成，并以 `login_success` 和 `userId`
  作为业务 API 的前置条件。
- 企业身份、授权、AIThread、Hermes 调度和审计属于 Gateway，不下沉到微信入口层。
- auth-token 仅用于 agent-wechat 接口认证，不能替代企业用户身份和业务授权。
- 消息、联系人和媒体属于敏感数据；日志与监控不得记录完整正文、账号标识或 token。

## 群聊上下文 Known Issue

目标群聊上下文按 `bot + group + sender` 隔离。Gateway V1 当前仍采用 whole-room
聚合，可能让同一群内不同发送者共享上下文；这是已知实现偏差，不代表最终的身份、
权限或 AIThread 模型。

## 未完成能力

- 图片理解和图片附件传递。
- 文件消息端到端处理、OCR 和压缩包内容解析。
- 企业知识库和 Skill 自动执行。
- 生产环境自动部署。

## VNC Known Issue

VNC 是登录和诊断通道，不是业务 API。其 interactive x11vnc 状态存在启动不稳定
问题，验证环境通过额外 systemd 修复服务恢复；调用链设计不能依赖 VNC 可用性。
