# 04 二开规划

## 说明

本文档仅记录可能的后续企业扩展方向，不代表已立项或已实现。具体设计应以 V1 验证结果、安全要求和业务优先级为依据。

## 规划方向

1. **Hermes Adapter**
   定义 CF_gateway 与 Hermes Agent 之间稳定、可测试的适配接口。

2. **企业用户身份映射**
   建立微信身份与企业内部账号、组织和角色的映射关系。

3. **权限控制**
   对 Agent、Skill、数据范围和高风险操作实施最小权限控制。

4. **文件处理流水线**
   建立文件接收、校验、解析、存储、扫描、处理和结果回传流程。

5. **审计日志**
   记录请求来源、授权决策、Agent 调用、自动化动作和执行结果，并控制敏感信息暴露。

6. **企业知识库连接**
   在身份与权限边界明确后，连接企业知识库并实现可追踪的检索与引用。

## 二开原则

未来如需二开，优先新增外围服务，尤其是独立的 CF_gateway；不要大规模修改 agent-wechat 核心。

- 少改核心：不直接在 agent-wechat 核心中承载企业业务逻辑。
- 补丁可追踪：必要的上游补丁使用独立提交并说明原因、范围和验证结果。
- 保持同步能力：企业扩展与上游源码保持清晰边界，避免阻断后续版本对比和同步。
- 文档同步：代码、接口、部署方式或安全边界变化时，同步更新对应文档。
- 每项能力在开发前补充接口设计、安全评估和验收标准。
