# 03 V1 验证计划

## 目标

验证 agent-wechat 作为企业 AI 微信入口的基础技术可行性，并为 CF_gateway 与 Hermes 接入设计提供事实依据。本计划仅记录后续验证项，当前阶段不执行测试。

## 1. 微信登录

测试项：

- 登录稳定性。
- 运行时是否需要 GUI。
- 长时间运行是否掉线，以及掉线后的表现。

## 2. 消息能力

测试范围：

- 私聊消息。
- 群聊消息。
- 群内 `@机器人`。
- 消息回复。

需要确认消息事件能否稳定提供：

- 用户 ID。
- 群 ID。
- 消息 ID。
- 消息时间。
- 可用于连续会话的上下文信息。

## 3. 文件能力

分别验证接收、识别元数据、下载或转交处理的可行性：

- 图片。
- Word。
- Excel。
- PPT。
- PDF。
- ZIP。

验证过程中应同时记录文件大小限制、格式识别准确性、临时文件行为和失败反馈。

## 4. Hermes 接入可能性

需要评估：

- agent-wechat 可用的消息输入与回复接口。
- CF_gateway 所需的最小消息契约。
- 同步与异步调用方式。
- 超时、重试和错误返回边界。
- 会话上下文与文件引用的传递方式。

本项只形成评估结论与接口建议，不在 V1 初始化阶段实现接入。
