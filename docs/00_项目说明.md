# 00 项目说明

## 项目名称

CF_agent-wechat

## 项目目标

使用 agent-wechat 作为外部依赖，建设企业级 AI 自动化系统的微信入口，并为后续企业桥接层与 AI Agent 执行能力预留清晰边界。

## agent-wechat 外部依赖说明

- 上游地址：<https://github.com/thisnick/agent-wechat>
- 本地目录：`agent-wechat/`，仅供本地验证并由 Git 忽略。
- 仓库边界：本仓库不包含、不修改、也不公开再分发上游源码。
- 参考验证基线：`f72e7552c04f8ffa0eab22f888985a4c79ee3a91`
- 初始化日期：2026-07-26
- 当前状态：外部依赖验证阶段。
- Git 管理：上游源码不纳入本项目 Git 历史。
- 修改边界：不修改上游核心代码。
- 后续扩展：如验证通过，优先在 `cf-gateway/` 增加 CF_gateway 企业桥接层。

## 当前阶段

当前处于 **V1 技术验证阶段**。

本阶段仅包含：

- 上游外部依赖确认。
- 根项目初始化。
- 项目文档建设。
- 后续验证范围定义。

本阶段不包含部署、服务启动、Hermes 接入、业务逻辑开发或 agent-wechat 核心功能修改。

## 企业应用方向

- 将员工微信作为企业 AI 自动化入口。
- 通过 CF_gateway 承载企业身份、权限、审计和适配逻辑。
- 通过 Hermes Agent 调度 Skills 与自动化流程。
- 在后续阶段连接企业知识库和文件处理能力。

## 维护原则

- `agent-wechat/` 作为本地外部依赖目录，不纳入本仓库。
- 上游版本和企业变更分别记录，确保依赖来源和项目修改可追踪。
- 功能开发以验证结果和正式设计为前提，不在初始化阶段提前实现。
