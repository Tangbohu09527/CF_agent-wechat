# 00 项目说明

## 项目目标

CF_agent-wechat 是企业 AI 自动化系统的微信入口层。项目使用 agent-wechat 运行
微信账号并提供通信接口，为规划中的 CF Gateway 和 Hermes Agent 提供稳定、
可验证的微信接入边界。

## 职责范围

### 负责

- 微信账号运行。
- 消息接收与发送。
- 联系人和聊天管理。
- 图片与文件的入口承接；具体能力以验证结果为准。
- 微信事件转发接口。
- 固定镜像版本、部署基线和验证记录。

### 不负责

- AI 推理与 Agent 决策。
- Skill 执行。
- ERP 或其他企业系统操作。
- 企业身份、权限、审计和业务逻辑。

上述企业能力应在 CF Gateway、Hermes Agent、Skills 和企业系统中实现，不能下沉
到微信入口层。

## 外部依赖

| 项目 | 值 |
| --- | --- |
| 上游 | <https://github.com/thisnick/agent-wechat> |
| 已验证 tag | `0.11.15` |
| 运行镜像 | `ghcr.io/thisnick/agent-wechat:0.11.15` |
| 部署固定方式 | `ghcr.io/thisnick/agent-wechat@sha256:<verified-digest>` |
| 仓库策略 | 不包含、不修改、不再分发上游源码 |

上游许可证和使用授权应由部署方独立确认。真实 digest 记录在受控部署记录中；公开
仓库只保留 digest 占位符，防止把未经复核的值复制到新环境。

## V1 状态

### Verified

- Debian 13 / Docker CE 环境部署和健康检查。
- 微信登录初始化流程。
- 联系人、聊天和消息读取。
- 私聊和群聊文本消息发送。
- 验证环境中的容器、agent-wechat 和 VNC 重启恢复。

### Pending

- 图片发送、文件发送。
- WebSocket 实时消息事件。
- CF Gateway / Hermes Agent 集成。

### Known Issue

- VNC 默认启动后的交互状态不稳定，需要额外的 x11vnc 恢复服务。
- VNC 修复资产和已验证的自动重启策略尚未完整反映在仓库部署文件中。

具体证据与限制见 [validation.md](validation.md)。
